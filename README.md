# 🧩 Cute Puzzles - Deslizante

Un divertido, moderno y desafiante rompecabezas deslizante interactivo desarrollado con **HTML5**, **CSS3** y **JavaScript vanilla**. Diseñado para ofrecer una experiencia visual atractiva y fluida tanto en dispositivos móviles como de escritorio.

---

## ✨ Características Principales

*   **Niveles de Dificultad Adaptativos:** Escoge entre tablero Fácil (3x3), Medio (4x4) o Difícil (5x5).
*   **Modos de Juego:** 
    *   *Modo Libre:* Juega sin prisa y relájate resolviendo el puzle.
    *   *Modo Crono:* Pon a prueba tu velocidad y compite contra el tiempo con el temporizador integrado.
*   **Sistema de Pistas Inteligentes:** ¿Te has quedado atascado? El sistema calcula los movimientos óptimos tras unos segundos de inactividad o al pulsar el botón de la bombilla con indicadores visuales animados.
*   **Efectos Inmersivos:** Sonidos interactivos personalizados para cada acción (movimientos, victorias, errores, pistas) y una celebración con **confeti** al completar el juego con éxito.
*   **Diseño 100% Responsivo:** Interfaz optimizada con diseño moderno, tipografías personalizadas de Google Fonts (*Fredoka* y *Lilita One*) y paleta de colores armoniosa.

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica de la aplicación y modales interactivos.
*   **CSS3:** Estilos avanzados, diseño con Grid/Flexbox, variables CSS y animaciones fluidas.
*   **JavaScript (ES6+):** Lógica del juego, algoritmos de resolución y gestión de eventos del DOM.
*   **Canvas Confetti:** Biblioteca externa para los efectos visuales de victoria.

---

## 🚀 Cómo Jugar

1. Haz clic en el botón **Inicio** desde la pantalla principal.
2. Selecciona las piezas vecinas al espacio vacío para deslizarlas ordenadamente hasta completar la imagen original.
3. Utiliza el menú superior de configuración para ajustar el sonido, activar la pantalla completa o consultar la sección de ayuda.
